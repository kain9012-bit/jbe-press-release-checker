# AI 중계 — 버셀 판 (상류: 오픈라우터)

웹페이지와 **같은 주소**에서 돈다. 그래서 CORS 도, 허용 주소 목록도 없다.
배포 주소가 바뀌어도 맞춰 줄 것이 없다.

클라우드플레어 Worker(`../proxy/`)와 하는 일은 같다. **둘 중 하나만 쓰면 된다.**
버셀에 올릴 거면 이쪽이 간단하다.

## 올리는 법

1. 깃허브 저장소를 버셀에 연결한다 (Import Project)
2. **Settings → Environment Variables** 에 넣는다

   | 이름 | 값 |
   |---|---|
   | `OPENROUTER_API_KEY` | 오픈라우터 키 (Secret) |
   | `VITE_PROXY_URL` | `/api/ai` — 안 넣으면 이 값이 기본이라 생략해도 된다 |

3. 배포한다

`VITE_PROXY_URL` 은 비밀이 아니다. 그냥 같은 주소 안의 길이다.
`OPENROUTER_API_KEY` 만 비밀이고, 그것은 브라우저로 나가지 않는다.

옛 배포본이 `VITE_PROXY_URL=/api/gemini` 를 쓰고 있어도 그대로 돈다
(`api/gemini/[model].js` 가 같은 알맹이를 가리키는 한 줄짜리다). 환경변수를 `/api/ai` 로
바꾼 뒤에는 그 파일을 지워도 된다.

이 값이 있으면 **담당자는 설정을 열 일이 없다.** 글을 넣고 ‘AI까지 검토’ 를 누르면 된다.

## 문을 어떻게 좁혔나

| | |
|---|---|
| 같은 주소에서 온 것만 | `Sec-Fetch-Site: same-origin`, 없으면 `Origin` 의 호스트 대조 |
| 정해 둔 모형만 | `ALLOWED_MODELS` |
| 64KB 이하만 | `MAX_BODY` |

주소 끝의 모형 이름만 보고 서버가 오픈라우터 이름(`google/gemini-3.6-flash`)으로 옮긴다.
**몸통에 적혀 온 `model` 은 믿지 않고 덮어쓴다** — 안 그러면 허용 목록이 아무 소용이 없다.
학습에 쓰는 경유지를 빼라고 `provider.data_collection: 'deny'` 도 서버가 붙인다.

**클라우드플레어 판과 달리 분당 횟수 제한이 없다.** 버셀 함수는 요청마다 따로 뜨는 것이라
숫자를 세어 둘 곳이 없다. 그러니 **오픈라우터 크레딧을 필요한 만큼만 채워 두어야 한다.**
선불이라 잔액이 곧 상한이다.

## 확인

```bash
node bench/vercel.test.mjs
```

같은 주소에서 온 것만 지나가고, 남의 사이트·표시 없는 요청·허용 안 된 모형·긴 원고·GET 이
막히는지 본다. 응답에 키가 섞여 나가지 않는 것도 본다.
